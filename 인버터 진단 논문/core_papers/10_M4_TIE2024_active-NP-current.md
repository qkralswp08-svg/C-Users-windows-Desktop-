## 1. 왜 읽어야 하는가
중성점 전류를 '능동 조정' 해 NP 전압 리플을 만들고, 스위칭 상태×3상 전류로 주입 NP 전류를 재구성해 RLS 로 C 를 추정한 3레벨 논문. 내 연구의 신호(NP 전류 재구성, NP 전압 리플)와 동일한 양을 다루므로 경쟁 선행이자 재구성 식의 공여자.

## 2. 내 연구와 같은 점
3레벨 · NP 전류 재구성(스위칭 상태×상전류) · NP 전압 리플 · 추가 센서 없음 · 온라인.

## 3. 내 연구와 다른 점
능동 조정(주입형). RLS(모델 기반). ESR 미확인. 데이터 기반 아님.

## 4. 집중해서 읽을 부분
(1) NP 전류 재구성 식(내 iNP 계산과 대조). (2) 조정 크기와 운전점 불변 주장의 근거. (3) NP 전압 리플 ↔ C 관계식. (4) 실험 조건·오차.

## 5. 타 토폴로지 이전 가능성
NPC/T-type 공통.

## 6. AI/ML/CNN 적용 가능성
재구성 NP 전류 스펙트럼을 CNN 입력으로 쓰는 전처리 근거.
