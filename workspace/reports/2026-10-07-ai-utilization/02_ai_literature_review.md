# 02. 전력전자 상태진단 분야 AI 활용 선행연구 조사 (Agent B·C·D 통합)

- 작성일: 2026-10-07
- 참고문헌 번호 `[n]`(외부 논문)과 `[Ln]`(연구실 논문)은 `06_reference_verification.md`의 최종 목록과 같다.
- **근거 수준(반드시 먼저 읽을 것)**: 모든 논문 정보는 **WebSearch 결과(제목·URL·초록 스니펫) 수준**이다. 이 컨테이너는 Crossref·doi.org·IEEE Xplore·MDPI·ScienceDirect 직접 조회가 네트워크 정책으로 막혀 있어 **본문을 한 편도 읽지 못했다.** 따라서 split 방식, 데이터 규모, 운전조건처럼 본문에만 있는 정보는 대부분 "논문에서 확인되지 않음(초록 수준)"이다. 이는 "그 논문이 하지 않았다"는 뜻이 아니다.
- 탐색 도중 세션 공유 WebSearch 한도(200회)가 소진되어 일부 서지(DOI)는 보완하지 못했다. 미보완 항목은 06 문서에 목록화했다.

## 2. 분야별 연구동향 (근거 중심)

### 2.1 A. AI 기반 전력전자 상태감시 — 리뷰

- [1]은 전력전자 AI 응용 500편 이상을 설계·제어·유지보수 단계 × 최적화·분류·회귀·데이터 탐색 과업으로 분류했다(초록). 진단은 "유지보수 × 분류/회귀"에 속한다.
- [2]는 전력전자 시스템 고장진단의 데이터 마이닝(ANN/ML/DL)을 체계적으로 리뷰하고, 측정 신호에서 특징을 스스로 추출하는 DL 기법이 다른 방법보다 효과적이라고 결론지었다(스니펫).
- (해석) 두 리뷰 모두 2021년까지의 문헌이며, 운전조건 일반화·평가 프로토콜을 별도 쟁점으로 다뤘는지는 초록에서 확인되지 않는다.

### 2.2 B·C. DC-link 커패시터 상태감시와 C/ESR 추정 AI

- 입력 표현은 크게 (i) 커패시터 전압·전류의 FFT 성분(2f, fsw) [L1], (ii) 주파수 대역 입력 [L2], (iii) DC-link 전압 리플 기반 특징 [5], (iv) pre-charge 과도(본 조사 후보, 서지 보완 필요)로 나뉜다.
- 연구실 선행 논문 [L1]은 단상 DC/AC 컨버터에서 실험 전압·전류의 FFT 성분(2배 기본파, 스위칭 주파수)을 DNN에 넣어 C와 ESR을 추정했고, [L2]는 3상 DC/AC에서 저주파 성분이 C에, 중간주파 성분이 ESR에 지배적이라는 특성을 이용해 DNN·CNN·Simple RNN·LSTM을 비교했다. **특정 성분만 넣으면 DNN, 넓은 대역을 넣으면 CNN이 우수**했다(스니펫).
- (해석) [L2]의 결과는 "모델 우열이 입력 표현에 따라 바뀐다"는 근거다. 즉 현재 코드의 CNN/LSTM/MLP/RF 비교는 입력 표현(원파형 vs 스펙트럼 대역)과 묶어 해석해야 한다.
- [5]는 AC/DC/AC 컨버터 DC-link 커패시터를 ML(이전 조사 기준 GPR, 리플 PSD)로 감시했다. 이전 조사(2026-09-29)에서 다중 운전조건 실험을 한 것으로 기록되었으나 이번 세션에서 재확인하지 못했다.
- 공통 한계: 핵심 논문 어느 것에서도 random split / 운전조건 split / 미관측 조건 시험이 초록 수준에서 확인되지 않았다.

### 2.3 E. 전력반도체 열화 AI

- [7]은 SiC MOSFET 전기·열 특성 추세를 비지도 학습으로 다룬 고장 예지 연구이며, "SiC 소자 prognostics를 다룬 첫 연구"라고 주장한다(초록).
- [8]은 power MOSFET 20개 stress test 데이터로 RF 분류(healthy/pre-failure)와 Bayesian Ridge RUL 회귀의 2단계 파이프라인을 제시했고, 분류 평균 정확도 80%, RUL RMSPE 1.25%를 보고했다(초록).
- [9]는 디지털 게이트 드라이버로 얻은 V_ge 파형을 CNN에 넣어 IGBT bond-wire lift-off를 4등급(no/light/medium/heavy)으로 분류했다(초록).
- (해석) 소자 열화 연구는 단품 가속시험 데이터가 주류이고, 표본 수(예: 20개)가 작다. 연구실 소자 논문 [L10], [L11]은 열화가 손실·인버터 성능에 주는 영향을 분석한 것으로, 스니펫에서는 AI 사용이 확인되지 않았다.

### 2.4 D·J. 인버터 고장진단 DL과 운전조건 일반화

- 인버터 DL 진단의 주류 대상은 **IGBT/스위치 개방고장(이산 사건)**이다([10][11][12], 리뷰 근거는 Agent B2 후보 B2-03). 커패시터 노화 같은 연속 열화를 DL로 다루며 운전조건 일반화를 평가한 연구는 이번 범위에서 확인하지 못했다.
- 운전조건·도메인 변화 대응은 세 갈래로 확인된다.
  - ① 시뮬레이션 → HIL fine-tuning(실 전력 하드웨어 실험 여부는 확인되지 않음): [10]은 시뮬레이션으로 사전학습한 경량 CNN을 HIL 소량 데이터로 미세조정해 정확도 99.52%(시뮬레이션), 98.30%(HIL)를 보고했다.
  - ② 비지도/부분 도메인 적응: [11]은 가중 source 데이터와 target 데이터의 Wasserstein 거리를 줄이는 partial transfer로 VSI 개방고장을 진단했다. 방법론 원전은 DANN [13]이다.
  - ③ 조건 순차 추가(lifelong): [12]는 운전조건이 추가될 때 catastrophic forgetting을 억제하는 lifelong learning을 제안했다.
- (해석) ①·②는 target 데이터(소량 라벨 또는 비라벨)를 전제한다. target 데이터 없이 처음 보는 조건에 대응하는 domain generalization은 전력전자에서 드물다(이번 범위 기준).
- **연구실 시사점**: 현재 코드는 "학습에 없는 운전조건" 시험을 이미 갖추었으므로, 이를 leave-one-condition-out으로 확장하면 위 연구들과 같은 축(운전조건 일반화)의 정량 결과를 낼 수 있다.

### 2.5 F·G·H. 아크 고장 AI (연구실 외부 연구)

- **임계값 vs AI**: [20]은 DC series arc 검출에서 rule-based와 AI 기반 방법을 비교해, AI가 변화하는 조건에 더 적응적이며 도메인 지식 기반 특징추출과 결합하면 성능이 좋아진다고 결론지었다(초록). 대상은 저샘플링·저연산 장치다.
- **부하 일반화**: 미관측 부하를 명시적으로 평가한 V1 연구는 같은 그룹의 [18](RLC 아크 모델로 합성한 데이터로 1D-CNN 학습, 미관측 부하 9종 평균 99.33%)과 [19](단일 부하 회로로 학습 → 미관측 다중부하 시험, 시간·주파수 regular coupling feature) 두 편이다.
- 고정 부하 집합에서 고정확도를 보고한 연구(예: [22] IEC 62606 부하 8종 최대 99.47%, [23] UL1699 준거 부하 5종 99.99%)는 split 방식과 미관측 부하 시험 여부가 초록에서 확인되지 않는다.
- **실시간**: [22]는 1 cycle당 평균 31 ms 실행시간, [21]은 single-board computer 실시간 동작(정확도 95.8%)을 보고했다.
- (해석) 이번에 확인한 미관측 부하 일반화 V1 2편([18], [19])은 "순수 end-to-end"가 아니라 물리 모델·도메인 특징을 결합한 방식이었다(초록 수준; [18]의 시험 데이터 실측 여부는 확인되지 않음). 연구실의 시간·주파수 하이브리드 특징 연구[L5][L8][L9]와 같은 방향이다.
- 연구실 DC 아크 AI 논문 [L5]–[L9]는 서지를 확인했으나 사용 모델 종류는 대부분 "learning models"로만 서술되어 있어 스니펫으로는 특정하지 못했다(01 문서 §4).

### 2.6 I. Physics-informed ML

- [6]은 DNN과 컨버터 동적 모델을 결합한 PIML로 Buck 컨버터 부품 파라미터를 추정했고, 순수 데이터 기반 방법의 학습 데이터·정확도·강건성 문제를 완화한다고 주장한다(초록).
- DC-link 커패시턴스에 생성 모델(diffusion) 증강 + physics-informed LSTM을 적용한 IEEE TIE 2025 논문이 검색되었으나 제목 후반부를 확인하지 못해 참고문헌에서 제외했다(06 문서 보류 목록).
- (해석) 인버터 DC-link 커패시터를 정상 운전 리플로 진단하는 PIML은 이번 범위에서 확인하지 못했다. 연구실이 보유한 DC-link 리플 물리(v ≈ ESR·i_C + ∫i_C/C)를 손실항·특징으로 넣는 연구는 차별점이 될 수 있다.

### 2.7 K·L. 자기지도 학습과 이상탐지

- [14]는 notch filter 증강으로 토크 조건에 불변한 특징을 학습하는 자기지도 학습으로 전동기 고장을 진단했다(초록). "보존할 정보(고장)는 남기고 바뀌어도 되는 정보(운전조건)는 지우는" 증강 설계가 핵심이다.
- [17]은 동기 측정한 진동·전류를 contrastive로 정렬해 전류 단독 진단 모델을 강화했다(초록).
- DC-link 커패시터 노화를 운전조건이 바뀌는 상황에서 비라벨 리플 전압으로 탐지한 2026년 논문(HTM 기반, Measurement: Energy)이 검색되었으나 저자를 확인하지 못해(X) 인용하지 않는다. 서지 보완 1순위다.
- (해석) 현장에는 노화 라벨이 거의 없으므로, 정상 데이터만으로 학습하는 조건부 이상탐지는 연구실 사업모델(현장 PoC)과 맞는다.

### 2.8 N. 설명가능 AI (XAI)

- 3-level NPC 인버터 고장 검출에서 CNN + Grad-CAM을 적용한 연구[15]가 확인되었다(시뮬레이션 + 실험).
- [16]은 에너지·전력 시스템 XAI 리뷰로, 높은 책임성이 요구되는 분야에서 black-box 모델 설명이 필요하다고 정리했다.
- (해석) 대부분 사후(post-hoc) 정성 설명이며, 설명이 물리량(고조파 성분, ESR/C 변화)과 맞는지 정량 검증한 사례는 초록에서 확인되지 않았다. 연구실 코드에 대역 occlusion과 Grad-CAM을 붙이면 "모델이 노화 관련 성분을 보는가"를 직접 검증할 수 있다.

### 2.9 M. Edge AI / TinyML / MCU

- 방법론 원전: int8 정수 전용 추론과 양자화 인지 학습[28], 지식 증류[29], 프루닝+양자화+Huffman 압축[30], 프루닝[31], TensorFlow Lite Micro[32], MLPerf Tiny 벤치마크[33], Cortex-M용 CMSIS-NN 커널[34]. 리뷰 [35].
- 전기설비 진단의 MCU 실구현 근거로 가장 강한 것은 UNC Charlotte 그룹의 아크 연작이다. [26]은 KD + TFLite로 STM32H743ZI2에서 추론 3 ms, 정확도 99.31%를, [25]는 파라미터 5.04k, 메모리 90 kB의 경량 CNN을 STM32H743ZI2 + 고체 차단기(SSCB)에 통합해 검출·차단 최소 19 ms, 오검출 억제용 5-cycle 확인 시 총 95 ms를 보고했다(초록, 두 편 모두 DOI 미확인).
- [27]은 ANPC 인버터 다중 개방고장을 edge 2D-CNN으로 실시간 진단했다(제목·DOI 확인, 장치 종류와 지연은 확인 못 함).
- [37]은 STM32H743VI에서 CNN 베어링 진단 1회 19 ms, 정확도 98.9%를 보고했다(arXiv).
- (사실) DC-link 커패시터 노화를 MCU 온보드 신경망으로 진단한 논문은 이번 범위에서 찾지 못했다(탐색 불완전 — ANN을 DSP에 통합했다는 검색 요약이 있었으나 서지를 특정하지 못함. 공백일 가능성이 있으나 단정하지 않음).

### 2.10 O. 멀티모달 센서 퓨전

- 전기기계 분야의 진동+전류 퓨전이 주류이며[17], 전력전자 부품 진단에서 전기+열 퓨전의 V1/V2 사례는 이번 범위에서 확보하지 못했다.
- (해석) 전해 커패시터 ESR의 온도 의존성을 고려하면, 커패시터 표면 온도를 보조 입력으로 쓰는 것이 노화와 온도 효과를 분리하는 데 필요하다(일반적 공학 판단, 본 조사 문헌 근거 없음).

## 3. AI 기술 분류와 연구실 문제 적합성

"근거"가 비어 있는 행은 **이번 조사에서 해당 기법을 전력전자 진단에 적용한 V1/V2 문헌을 확보하지 못한 것**이며, 설명은 일반 방법론 지식이다.

| 분류 | 기법 | 핵심 원리(요약) | 근거 | 연구실 문제 적합성 | 주의점 |
|---|---|---|---|---|---|
| 전통 ML | SVM | 마진 최대화 분류 | (연구실 아크 논문은 "learning models" 비교로만 확인) | 소량 데이터의 수작업 특징(대역 에너지, RMS) 기반 노화 분류 | 특징 설계에 성능 의존 |
| 전통 ML | Random Forest | 트리 앙상블 | [8] | 특징 기반 진단의 강한 기준선, 특징 중요도 | **raw 2048점 입력은 부적합**(위상 비정렬) — 04 문서 |
| 전통 ML | XGBoost / kNN / PCA+분류기 | 부스팅 / 거리 / 차원축소 | — | 특징 기반 기준선, 이상탐지(kNN 거리) | 특징 스케일·조건 의존 |
| DL | MLP | 완전연결 | [L2] | 스펙트럼 특징 입력 회귀(C/ESR) | 원파형 입력 시 파라미터 과다·위치 의존 |
| DL | 1D CNN | 국부 필터 + 풀링 | [L2][18][22] | 리플·전류 원파형 진단(현재 코드의 기준 모델) | 진폭 보존 시 센서 이득·부하에 민감 |
| DL | 2D CNN | 시간-주파수 영상 | [27] | 스펙트로그램 기반 진단 | 변환 비용(MCU) |

| 비지도/반지도 | Autoencoder / VAE | 재구성 오차 | — (HTM 기반 연구는 X) | 정상 데이터만으로 노화 이상 탐지 | 운전조건 변화와 노화 이동의 구분 필요 |

## 4. 선행연구 평가 관행에 대한 종합 판단

| 확인 항목 | 이번 조사 결과 |
|---|---|
| random split 여부 | 핵심 18편 중 초록에서 명시 확인 0편 |

| 실험 vs 시뮬레이션 | 실험 명시: [L1][9][19][23][25]; 실측 추정(초록 미명시): [21]; 시뮬레이션 학습: [18]; sim+HIL: [10] |
