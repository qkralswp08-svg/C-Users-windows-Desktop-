| iSa2 | a상 Sa2 스위치 전류. P·O 상태에서 도통 → 상전류 양의 반주기 위주 | 기준 방향 확인 필요 |
| iNP | 중성점 전류 (O 상태인 상들의 상전류 합) | 저주파 3f1 성분이 대표적 |

| ESR | Equivalent Series Resistance. 노화 시 증가(전해). 온도·주파수 의존 | 고주파 리플에서 추정 |
| C (capacitance) | 정전용량. 노화 시 감소 | 저주파 충방전에서 추정 |
| 리플 전류 / 전압 | 커패시터에 흐르는 교류 성분 / 그로 인한 전압 변동 | 발열 P = ESR·I_rms² |
| 고조파 차수 h | f / f1. 2n 계열 = 짝수 고조파 | 반파 정류형 파형은 DC + f1 + 짝수 고조파 |
| 스위칭 측대파 | m·fsw ± n·f1 성분 | 변조 방식에 따라 분포 변화 |

| CNN input feature | 노화 추정 모델 입력 (파형 조각, 스펙트럼, 고조파 벡터 등) | 프로젝트 정의 확인 |
| Research Gap | 문헌에서 비어 있는 조합(신호 × 방법 × 토폴로지 × 검증) | 근거 논문 필요 |
