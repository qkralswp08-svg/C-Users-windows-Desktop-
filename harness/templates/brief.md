## 작업 방법

1. 아래 "적용할 Skill" 절의 지침을 **순서대로** 적용하라. 앞 Skill의 결과가 뒤 Skill의 입력이 된다.
2. 프로젝트 맥락은 CLAUDE.md 와 context/project-context.md 에 이미 로드되어 있다. 코드·데이터·논문은 필요할 때 직접 탐색해서 읽어라. 프로젝트 전체를 한꺼번에 읽지 마라.
3. 분석과 수정을 구분하라. 파일 수정이 필요하면 문제·원인·영향·수정 방향을 먼저 설명하고, 연구 코드(MATLAB/Python)는 사용자 확인 후에만 수정하라.
4. 사실(파일·논문에서 직접 확인)과 해석, 추론을 구분해서 표기하라. 확인하지 못한 것은 "확인하지 못함"이라고 써라.
5. 답변은 한국어로 하되, 변수명·함수명·전문용어는 원문 그대로 사용하라.

## 마무리

작업이 끝나면 마지막에 다음을 수행하라.

- 결과를 짧게 요약하라 (핵심 결론 → 근거 → 다음 단계).
- 이번 작업이 이후에도 참고할 가치가 있으면 `context/research-log.md` 맨 아래에 아래 형식으로 3~6줄 항목을 추가하라. 단순 질의응답이면 생략해도 된다.

```
## {{DATE_SHORT}} — (한 줄 제목)
- 요청: ...
- Skill: {{SKILL_NAMES}}
- 결과: ...
- 다음: ...
```
